Mảng queue_numbers được khai báo kích thước là 4, nghĩa là các chỉ số hợp lệ để truy cập phần tử trong mảng chỉ nằm trong khoảng từ 0 đến 3.Dòng lệnh gây lỗi trong mã nguồn cũ:queue_numbers[patient_position] = new_queue_number;Vì biến patient_position có giá trị là 4 (vị trí đếm theo cách của con người), hệ thống sẽ truy cập vào queue_numbers[4].
